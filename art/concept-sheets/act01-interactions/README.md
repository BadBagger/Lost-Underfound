# Act 1 Interaction Animation Concept Sheets

These sheets are source concept passes for item interaction animation. They are not final registration-approved production sprites yet.

Each sheet uses a flat pink background so frames can be isolated, reviewed, and sliced for prototype playback. Before any sheet becomes production art, it still needs the Animation Bible workflow: registration check, cast-scale check, onion-skin review, and cleanup of any drift, cropping, baked shadows, or detached parts.

Included:

- `pip-pickup-item-36-grid.png` - Pip notices, crouches, grips, lifts, and settles with a small found item.
- `pip-handoff-bramble-36-grid.png` - Pip presents an item to Bramble across the desk; Bramble receives and inspects it.
- `pip-handoff-old-bottlecap-36-grid.png` - Pip offers an item to Old Bottlecap at the gate; Bottlecap reacts, accepts, and settles.
- `pip-goofy-throw-failed-handoff-grid.png` - Alternate exaggerated throw / failed handoff gag with smear timing. This is useful for motion language but is not a clean final handoff strip.
